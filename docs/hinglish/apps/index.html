Free apps aur tools

Chhote, halke aur free web apps jo phone pe app ki tarah install ho jaate hain. Zyadatar apps aapka data aapke hi phone pe rakhte hain.

📒 Free app

Hisab Kitab

Roz ka kharcha, aamdani aur udhaar-len-den likho. Data aapke phone ya aapki apni Google Drive mein rehta hai. Install hota hai, offline chalta hai.

 💌 Free tool

Wish Card Maker

Tyohar chuno, naam likho, sundar greeting card banao aur WhatsApp pe bhejo ya download karo.

▶️ Hisab Kitab: video dekhiye, app chalaiye

Install kaise karein

Android pe Chrome mein app kholo aur menu (⋮) se Install app / Add to Home screen chuno. iPhone pe Safari mein Share button daba ke Add to Home Screen chuno.

Ye apps kyun banaye

Roz ke chhote kaam — jaise kisko kitne paise diye, mahine mein kahan kitna kharcha hua, ya kisi ko sundar wish card bhejna — inke liye bhaari app download karne ya account banane ki zaroorat nahi honi chahiye. Hamare web apps kuch hi second mein khulte hain, phone mein bahut kam jagah lete hain aur saste phone pe bhi aaraam se chalte hain.

Aapka data aapke paas

Hisab Kitab aapka poora hisaab aapke hi phone ke browser mein rakhta hai; chaho to aap iska backup file ke roop mein le sakte ho. Wish Card Maker aapka naam ya message kisi server pe nahi bhejta. Dhyaan rakho: browser ka data mitaane pe app ka data bhi mit sakta hai, isliye zaroori hisaab ka backup rakho.
