🚗 Learner Licence (LL) online kaise banaye

Aakhri baar jaancha gaya: 26 November 2026

Ek nazar mein

Kahansarathi.parivahan.gov.in (parivahan.gov.in se) — apna state chunein
Umar50cc tak bina gear wala two-wheeler: 16 saal (parent ki sehmati); baaki gaadiyan: 18 saal — portal par dekhein
FeesAapke state ke liye portal par dikhegi
ValidityLL 6 mahine; pakke DL ka test 30 din baad aur LL khatam hone se pehle

Official website kholein ↗

📄 Kya-kya chahiye

  • Aadhaar number aur Aadhaar se juda mobile (OTP ke liye)
  • Aadhaar mein likha address — isi se RTO apne aap tay hota hai
  • Photo aur signature (Aadhaar e-KYC se photo aksar apne aap aa jaati hai)
  • 40 saal se zyada umar ho to doctor ka medical certificate (Form 1A)
  • 18 se kam umar ho to mata-pita/guardian ki sehmati
  • Online test ke liye camera wala phone/laptop aur achhi roshni

1Sarathi portal kholein aur state chunein

parivahan.gov.in → Online Services → Driving Licence Related Services par jaayein, ya seedhe sarathi.parivahan.gov.in kholein. List se apna state chunein — har state ka page thoda alag dikh sakta hai.

Yahan kya bharein:

  • State
  • Bhasha (Hindi/English)

Official website kholein ↗

2"Apply for Learner Licence" chunein aur Aadhaar e-KYC karein

Learner Licence menu mein naye LL ka option chunein. Aadhaar number daalein, Aadhaar se jude mobile par aaya OTP bharein. "Mere paas koi driving/learner licence nahi hai" wala option chunein. e-KYC ke baad aapka naam, address aur photo apne aap bhar jaate hain.

Yahan kya bharein:

  • Aadhaar number
  • Aadhaar OTP
  • Applicant category

Official website kholein ↗

3Form bharein aur documents upload karein

Pita/guardian ka naam, padhai, blood group, mobile check karein. Gaadi ki category (Class of Vehicle) chunein — jaise bina gear two-wheeler (MCWOG), gear wala two-wheeler (MCWG), car (LMV). Self-declaration (Form 1) bharein. 40+ umar par Form 1A upload karein. Application number SMS par aayega — use likh lein.

Yahan kya bharein:

  • Class of Vehicle
  • Self-declaration
  • Zaroori documents upload
  • Application number sambhalein

Official website kholein ↗

4Fees bharein aur road safety video dekhein

Portal par aapke state aur chuni gayi categories ke hisaab se fees dikhegi — UPI, card ya net banking se bharein aur receipt rakhein. Kai states mein test se pehle road safety ka tutorial video poora dekhna hota hai (aage skip nahi kar sakte).

Yahan kya bharein:

  • Fees payment
  • Receipt download
  • Tutorial video (OTP se)

Official website kholein ↗

5Online LL test dein aur licence download karein

Jin states mein ghar se test ki suvidha hai, wahan Aadhaar aur face authentication ke baad phone/laptop par test hota hai; baaki states mein RTO par slot book karke test hota hai. Sawal traffic signs, sadak ke niyam aur safe driving par hote hain. Pass hone par LL wahin se download karein.

Yahan kya bharein:

  • Test ka password (SMS)
  • Face authentication
  • LL download karein

Official website kholein ↗

🔍 Status kaise dekhein

sarathi.parivahan.gov.in par apna state chunkar "Application Status" ya "Complete your pending application" mein application number aur date of birth daalein. Beech mein chhoota application yahin se poora kar sakte hain. LL milne ke 30 din baad aur 6 mahine ke andar pakke driving licence (DL) ke test ka slot isi portal se book karein.

❌ In wajahon se aavedan atakta/reject hota hai

  • Test mein zaroori marks nahi aaye — portal par dobara test dein (re-test fees portal par dikhegi)
  • Face authentication fail — roshni mein, saamne dekhkar, akele baithkar test dein; kisi aur ki awaaz ya madad se test cancel ho sakta hai
  • Aadhaar se juda mobile paas nahi — OTP nahi aayega; pehle Aadhaar mein number theek karaayein
  • Galat Class of Vehicle chuni — jo gaadi chalani hai wahi category chunein
  • Nakli website ya agent ko paise de diye — sirf parivahan.gov.in aur sarathi.parivahan.gov.in use karein
⚠️ Dhokhe se bachein
  • Sirf .gov.in wali (ya upar di gayi) official site use karein.
  • OTP, Aadhaar ki poori jaankari ya password kisi ko na batayein — phone par bhi nahi.
  • "Pakka kaam" ke naam par zyada paise maangne wale agents se bachein.

Aksar poochhe jaane wale sawaal

Kya ghar baithe learner licence ban sakta hai?

Haan, kai states mein — Sarathi par Aadhaar e-KYC karke aur ghar se face authentication wala online test dekar, bina RTO gaye. Kuch states mein test abhi bhi RTO par hota hai; portal par apne state ka option dekhein.

Learner licence ki fees kitni hai?

Fees state aur gaadi ki category par nirbhar karti hai aur portal par payment ke samay dikhti hai. Zyada paise maangne wale agent se bachein — kisi agent ki zaroorat nahi hai.

LL kitne din chalta hai aur pakka DL kab banega?

Learner licence 6 mahine valid rehta hai. LL milne ke kam se kam 30 din baad aur uske khatam hone se pehle pakke DL ka driving test de sakte hain.

Learning licence test online mein kya poochha jaata hai?

Traffic signs (sign board), sadak ke niyam, overtaking, parking aur safety se jude multiple-choice sawal. Pass marks state ke niyam se tay hote hain aur test se pehle dikhte hain.

LL par akele gaadi chala sakte hain?

Nahi. LL par gaadi chalate samay pakke licence wala vyakti saath hona chahiye (two-wheeler par niyam state ke anusaar dekhein) aur gaadi par "L" ka nishaan lagana hota hai.

📌 Dhyaan dein: yeh steps aaj ke hisaab se likhe hain. Sarkari websites apne page, button aur fees samay-samay par badalti rehti hain — aap jab karenge tab kuch naam alag dikh sakte hain; tab official site par di jaankari hi maanein. Hum is guide ko update karte rahenge.
