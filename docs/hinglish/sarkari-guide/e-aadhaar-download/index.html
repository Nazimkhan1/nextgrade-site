📥 e-Aadhaar (Aadhaar PDF) download kaise karein

Aakhri baar jaancha gaya: 26 November 2026

Ek nazar mein

KahanmyAadhaar portal (uidai.gov.in ka)
FeesFree
ZarooriAadhaar se juda mobile (OTP)
PDF passwordNaam ke pehle 4 akshar (CAPITAL) + janm saal

Official website kholein ↗

📄 Kya-kya chahiye

  • Aadhaar number ya Enrolment ID (EID) ya VID
  • Aadhaar se juda mobile number

1"Download Aadhaar" kholein

myaadhaar.uidai.gov.in → "Download Aadhaar".

Yahan kya bharein:

  • Aadhaar number / EID / VID chunein
  • Number aur captcha

Official website kholein ↗

2OTP se pushti

Aadhaar se jude mobile par OTP aayega.

Yahan kya bharein:

  • OTP
  • "Masked Aadhaar" chahein to chunein (pehle 8 ank chhupe rahenge)

Official website kholein ↗

3PDF kholein

Download hui PDF password maangegi — naam ke pehle 4 akshar CAPITAL mein + janm saal. Jaise RAHUL, 1990 → RAHU1990.

Yahan kya bharein:

  • Password: pehle 4 akshar + YYYY

Official website kholein ↗

🔍 Status kaise dekhein

e-Aadhaar utna hi maanya hai jitna chhapa hua Aadhaar. Chahein to mAadhaar app ya DigiLocker mein bhi rakh sakte hain.

❌ In wajahon se aavedan atakta/reject hota hai

  • Mobile Aadhaar se juda nahi — OTP nahi aayega; pehle Aadhaar kendra par mobile judwayein
  • Password mein chhote akshar likh diye — CAPITAL mein likhein
  • Naam 4 akshar se chhota ho to jitne akshar hain utne + saal
⚠️ Dhokhe se bachein
  • Sirf .gov.in wali (ya upar di gayi) official site use karein.
  • OTP, Aadhaar ki poori jaankari ya password kisi ko na batayein — phone par bhi nahi.
  • "Pakka kaam" ke naam par zyada paise maangne wale agents se bachein.

Aksar poochhe jaane wale sawaal

e-Aadhaar download ki fees kitni hai?

e-Aadhaar download karna free hai.

Aadhaar PDF ka password kya hota hai?

Aadhaar mein likhe naam ke pehle 4 akshar CAPITAL mein aur janm saal (YYYY), jaise RAHU1990.

Masked Aadhaar kya hai?

Jisme Aadhaar number ke pehle 8 ank chhupe rehte hain — hotel wagairah mein dene ke liye surakshit.

📌 Dhyaan dein: yeh steps aaj ke hisaab se likhe hain. Sarkari websites apne page, button aur fees samay-samay par badalti rehti hain — aap jab karenge tab kuch naam alag dikh sakte hain; tab official site par di jaankari hi maanein. Hum is guide ko update karte rahenge.
