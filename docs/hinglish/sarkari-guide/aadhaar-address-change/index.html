🏠 Aadhaar mein address kaise badlein (online)

Aakhri baar jaancha gaya: 26 November 2026

Ek nazar mein

KahanmyAadhaar portal (uidai.gov.in ka)
ZarooriAadhaar se juda mobile number (OTP aayega)
FeesPortal par dikhegi — UIDAI ke anusaar abhi ₹75
SamayAamtaur par kuch din se 30 din

Official website kholein ↗

📄 Kya-kya chahiye

  • Address proof — jaise bijli/paani/gas bill (3 mahine se purana nahi), bank passbook/statement, passport, voter ID, rent agreement (registered)
  • Document par aapka naam Aadhaar jaisa hi ho
  • Saaf scan/photo — PDF, JPG ya PNG (size portal batayega)

1myAadhaar par login karein

myaadhaar.uidai.gov.in kholein → Login.

Yahan kya bharein:

  • Aadhaar number (12 ank)
  • Captcha
  • Mobile par aaya OTP

Official website kholein ↗

2"Address Update" chunein

Dashboard par "Document Update / Address Update" (naam thoda alag dikh sakta hai) → "Update Aadhaar Online".

Yahan kya bharein:

  • Address chunein
  • "Proceed to Update Aadhaar"

Official website kholein ↗

3Naya address bharein

Purana address dikhega; neeche naya address bharein.

Yahan kya bharein:

  • C/O (kiske yahan)
  • Makaan number, gali, mohalla
  • Gaon/sheher, post office, zila, rajya, PIN code
  • Bhasha wala hissa (Hindi mein address) jaanch lein

Official website kholein ↗

4Document upload karein

List se apna document chunein aur file upload karein.

Yahan kya bharein:

  • Document type — jaise Electricity Bill
  • File — saaf, poora page, naam aur pata dikhe

Official website kholein ↗

5Fees bharein aur URN sambhaalein

Online fees bharein (UPI/card/net banking). Aakhir mein URN (Update Request Number) milega — screenshot le lein.

Yahan kya bharein:

  • Payment
  • URN likh/sambhaal lein

Official website kholein ↗

🔍 Status kaise dekhein

myAadhaar par "Check Enrolment & Update Status" mein URN daal kar status dekhein. Update hone ke baad "Download Aadhaar" se naya e-Aadhaar download karein.

❌ In wajahon se aavedan atakta/reject hota hai

  • Document par naam Aadhaar se alag
  • Dhundhli ya kati hui photo
  • Purana bill (3 mahine se zyada)
  • PIN code ya zila galat
⚠️ Dhokhe se bachein
  • Sirf .gov.in wali (ya upar di gayi) official site use karein.
  • OTP, Aadhaar ki poori jaankari ya password kisi ko na batayein — phone par bhi nahi.
  • "Pakka kaam" ke naam par zyada paise maangne wale agents se bachein.

🧰 Form ke liye kaam ke tools

Photo aur signature ko sahi size/KB mein karein Photo ko 20/50/100 KB mein karein PDF chhota karein Photo se PDF banayein

Aksar poochhe jaane wale sawaal

Aadhaar mein address badalne mein kitna samay lagta hai?

Aamtaur par kuch din; zyada se zyada 30 din tak. Status URN se dekhein.

Kya bina document ke address badal sakte hain?

Parivaar ke mukhiya (Head of Family) ke document aur sahmati se address badalne ki suvidha bhi hai; vikalp portal par dekhein.

Mobile number Aadhaar se juda nahi hai to?

Pehle Aadhaar kendra jaakar mobile number judwayein (appointment appointments.uidai.gov.in se). Online update ke liye OTP zaroori hai.

📌 Dhyaan dein: yeh steps aaj ke hisaab se likhe hain. Sarkari websites apne page, button aur fees samay-samay par badalti rehti hain — aap jab karenge tab kuch naam alag dikh sakte hain; tab official site par di jaankari hi maanein. Hum is guide ko update karte rahenge.

NextGrade koi sarkari website nahi hai. Yeh jaankari logon ki madad ke liye hai; aavedan sirf official website par hi karein.
