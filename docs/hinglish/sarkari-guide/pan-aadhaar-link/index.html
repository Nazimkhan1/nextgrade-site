🔗 PAN ko Aadhaar se link kaise karein

Aakhri baar jaancha gaya: 26 November 2026

Ek nazar mein

KahanIncome Tax ka e-filing portal (incometax.gov.in)
Fees₹1,000 (late linking fees) — pehle bharni hoti hai
ZarooriPAN, Aadhaar, Aadhaar se juda mobile
AsarLink na hone par PAN "inoperative" ho sakta hai

Official website kholein ↗

📄 Kya-kya chahiye

  • PAN number
  • Aadhaar number
  • Aadhaar se juda mobile (OTP ke liye)
  • PAN aur Aadhaar mein naam, janmtithi, ling ek jaise hon

1Pehle link ka status dekhein

incometax.gov.in → "Link Aadhaar Status" — shayad pehle se link ho.

Yahan kya bharein:

  • PAN
  • Aadhaar number

Official website kholein ↗

2₹1,000 fees bharein (e-Pay Tax)

Portal par "e-Pay Tax" → PAN aur mobile daalein → OTP → "Income Tax" → Assessment Year → Type of Payment "Other Receipts (500)" → fees bharein.

Yahan kya bharein:

  • PAN (do baar)
  • Mobile number aur OTP
  • Assessment Year (portal batayega)
  • Type: Other Receipts (500)
  • Payment — net banking/UPI/card (bank list portal par)

Official website kholein ↗

3Aadhaar link ki request daalein

Payment ke kuch samay baad (aamtaur par 4–5 din tak lag sakte hain) home page → "Link Aadhaar".

Yahan kya bharein:

  • PAN
  • Aadhaar number
  • Aadhaar mein likha naam
  • Mobile par aaya OTP

Official website kholein ↗

4Pushti aur status

Submit ke baad sandesh aayega. Kuch din baad "Link Aadhaar Status" mein "linked" dikhna chahiye.

Yahan kya bharein:

  • PAN
  • Aadhaar number

Official website kholein ↗

🔍 Status kaise dekhein

incometax.gov.in → "Link Aadhaar Status" (bina login ke bhi). Link hone ke baad inoperative PAN phir se chalu hone mein kuch din lag sakte hain.

❌ In wajahon se aavedan atakta/reject hota hai

  • PAN aur Aadhaar mein naam/janmtithi/ling alag — pehle jisme galti hai use sudhaarein
  • Fees galat "Type of Payment" mein bhar di
  • Fees bharne ke turant baad link ki koshish — thoda rukein
⚠️ Dhokhe se bachein
  • Sirf .gov.in wali (ya upar di gayi) official site use karein.
  • OTP, Aadhaar ki poori jaankari ya password kisi ko na batayein — phone par bhi nahi.
  • "Pakka kaam" ke naam par zyada paise maangne wale agents se bachein.

Aksar poochhe jaane wale sawaal

PAN-Aadhaar link ki fees kitni hai?

₹1,000 — yeh late linking fees hai aur link ki request se pehle bharni hoti hai.

Kya sabko link karna zaroori hai?

Zyaadatar PAN dhaarakon ke liye haan; kuch logon (jaise 80 saal se upar, kuch NRI) ko chhoot hai — portal par niyam dekhein.

Naam match nahi ho raha to?

Aadhaar mein galti ho to myAadhaar se sudhaarein, PAN mein ho to PAN correction ka aavedan karein; phir link karein.

📌 Dhyaan dein: yeh steps aaj ke hisaab se likhe hain. Sarkari websites apne page, button aur fees samay-samay par badalti rehti hain — aap jab karenge tab kuch naam alag dikh sakte hain; tab official site par di jaankari hi maanein. Hum is guide ko update karte rahenge.
