📱 Aadhaar mein mobile number kaise badlein

Aakhri baar jaancha gaya: 26 November 2026

Ek nazar mein

KahanUIDAI ka naya Aadhaar App (Android/iPhone) — ya Aadhaar kendra
ZarooriPurana number chalu ho (OTP) + face authentication
FeesApp mein dikhegi — khabron ke anusaar ₹75
Helpline1947 (UIDAI)

Official website kholein ↗

📄 Kya-kya chahiye

  • Aadhaar number
  • Purana (Aadhaar se juda) mobile — OTP ke liye
  • Naya mobile number — is par bhi OTP aayega
  • Achhi roshni mein chehra (face authentication)
  • Purana number band ho to: Aadhaar kendra jaana hoga, koi document nahi — sirf Aadhaar aur biometric

1Official Aadhaar App install karein

Play Store/App Store mein "Aadhaar" khojein — publisher UIDAI wala hi app lein (nakli app se bachein). Yeh app 28 January 2026 ko shuru hua.

Yahan kya bharein:

  • Publisher: Unique Identification Authority of India

Official website kholein ↗

2Apna Aadhaar profile jodein

App mein Aadhaar number daalein, purane mobile par aaya OTP bharein aur chehra scan karein. Ek phone mein parivaar ke 5 profile rakh sakte hain.

Yahan kya bharein:

  • Aadhaar number
  • OTP (purane number par)
  • Face scan

Official website kholein ↗

3"Mobile Number Update" chunein

Services → My Aadhaar Update → Mobile Number Update (naam thoda alag dikh sakta hai) → naya number daalein → naye number par aaya OTP bharein.

Yahan kya bharein:

  • Naya mobile number
  • Naye number ka OTP

Official website kholein ↗

4Chehre se pushti aur fees

Face authentication karein aur app mein dikhi fees UPI/card se bharein. Aakhir mein mila request number (URN/SRN) ka screenshot rakhein.

Yahan kya bharein:

  • Face authentication
  • Fees payment
  • Request number sambhalein

Official website kholein ↗

5Purana number nahi hai? Aadhaar kendra jaayein

Purana number band/kho gaya ho to app se nahi hoga. appointments.uidai.gov.in par Aadhaar Seva Kendra ka time lein (ya paas ke Aadhaar kendra/post office jaayein), biometric se naya number jud jaayega.

Yahan kya bharein:

  • Shehar aur kendra chunein
  • Seva: mobile update
  • Aadhaar saath le jaayein

Official website kholein ↗

🔍 Status kaise dekhein

App mein update ka status dikhta hai; myaadhaar.uidai.gov.in par "Check Enrolment & Update Status" mein request number se bhi dekh sakte hain. Update hone ke baad naye number par OTP aane lagega. Madad ke liye 1947.

❌ In wajahon se aavedan atakta/reject hota hai

  • Purana number saath nahi — app se nahi hoga, kendra jaayein
  • Kam roshni/chashme ki chamak se face authentication fail — roshni mein dobara karein
  • Nakli app ya agent ko OTP de diya — sirf UIDAI ka app use karein
  • Naya number band ya chalu nahi — chalu SIM hi daalein
⚠️ Dhokhe se bachein
  • Sirf .gov.in wali (ya upar di gayi) official site use karein.
  • OTP, Aadhaar ki poori jaankari ya password kisi ko na batayein — phone par bhi nahi.
  • "Pakka kaam" ke naam par zyada paise maangne wale agents se bachein.

Aksar poochhe jaane wale sawaal

Kya ghar baithe Aadhaar mein mobile number badal sakte hain?

Haan — UIDAI ke naye Aadhaar App (28 January 2026 se) mein, agar purana number aapke paas hai. UIDAI ke anusaar February 2026 tak 10 lakh log app se number badal chuke the.

Purana number band ho gaya to?

Tab Aadhaar kendra jaana hoga; appointments.uidai.gov.in par time le sakte hain. Koi document nahi lagta, biometric se pushti hoti hai.

Mobile number badalne ki fees kitni hai?

App ya kendra par jo fees dikhe wahi dein — khabron mein ₹75 batayi gayi hai. Zyada maange to 1947 par shikayat karein.

Email bhi badal sakte hain?

Haan, Aadhaar mein email update bhi hota hai; app/portal mein "Email" option dekhein.

📌 Dhyaan dein: yeh steps aaj ke hisaab se likhe hain. Sarkari websites apne page, button aur fees samay-samay par badalti rehti hain — aap jab karenge tab kuch naam alag dikh sakte hain; tab official site par di jaankari hi maanein. Hum is guide ko update karte rahenge.
