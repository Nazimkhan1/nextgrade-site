🗳️ Naya voter ID kaise banwayein (Form 6)

Aakhri baar jaancha gaya: 26 November 2026

Ek nazar mein

Kahanvoters.eci.gov.in ya Voter Helpline app
FeesFree
Kaun18 saal ya zyada umar ka Bharatiya nagrik
FormNaya naam: Form 6 (videsh mein rehne wale: 6A)

Official website kholein ↗

📄 Kya-kya chahiye

  • Pehchaan ka praman — jaise Aadhaar, passport, driving licence
  • Pate ka praman
  • Umar/janmtithi ka praman
  • Haal ki passport size photo

1Account banayein

voters.eci.gov.in → Sign up — mobile aur OTP.

Yahan kya bharein:

  • Mobile number
  • Naam, password
  • OTP

Official website kholein ↗

2Form 6 chunein

"New registration for general electors (Form 6)".

Yahan kya bharein:

  • Rajya, zila, vidhan sabha kshetra
  • Naam, janmtithi, ling
  • Rishtedaar (pita/mata/pati) ka naam

Official website kholein ↗

3Pata aur documents

Poora pata bharein aur documents upload karein.

Yahan kya bharein:

  • Makaan no., gali, gaon/sheher, PIN
  • Photo (size portal batayega)
  • Pehchaan/pata/umar praman

Official website kholein ↗

4Submit aur reference number

Ghoshna padh kar submit karein; reference number sambhaalein. BLO ghar aakar jaanch kar sakte hain.

Yahan kya bharein:

  • Reference number

Official website kholein ↗

🔍 Status kaise dekhein

voters.eci.gov.in → "Track Application Status" mein reference number daalein. Manzoori ke baad "e-EPIC Download" se digital voter card free download karein; chhapa card daak se aata hai.

❌ In wajahon se aavedan atakta/reject hota hai

  • Photo dhundhli ya galat size
  • Pate ka praman kisi aur pate ka
  • Pehle se kisi aur jagah naam darj — do jagah naam rakhna mana hai
⚠️ Dhokhe se bachein
  • Sirf .gov.in wali (ya upar di gayi) official site use karein.
  • OTP, Aadhaar ki poori jaankari ya password kisi ko na batayein — phone par bhi nahi.
  • "Pakka kaam" ke naam par zyada paise maangne wale agents se bachein.

🧰 Form ke liye kaam ke tools

Photo aur signature ko sahi size/KB mein karein Photo ko 20/50/100 KB mein karein PDF chhota karein Photo se PDF banayein

Aksar poochhe jaane wale sawaal

Voter ID banwane ki fees kitni hai?

Naya voter ID banwana free hai.

17 saal mein aavedan kar sakte hain?

17 saal poore hone par pehle se aavedan kar sakte hain; naam 18 saal hone par (tay tareekhon par) judta hai — portal par niyam dekhein.

e-EPIC kya hai?

Voter card ka digital (PDF) roop, jo free download hota hai.

📌 Dhyaan dein: yeh steps aaj ke hisaab se likhe hain. Sarkari websites apne page, button aur fees samay-samay par badalti rehti hain — aap jab karenge tab kuch naam alag dikh sakte hain; tab official site par di jaankari hi maanein. Hum is guide ko update karte rahenge.

NextGrade koi sarkari website nahi hai. Yeh jaankari logon ki madad ke liye hai; aavedan sirf official website par hi karein.
