How to anchor a school programme

The anchor holds the whole programme together — welcoming the guests, calling every performance with respect and keeping the event on time. A typical 26 January order is: welcome, flag hoisting and national anthem, lamp lighting, welcome address, cultural programme, chief guest’s address, prize distribution and vote of thanks.

This script follows that order. With two anchors, the parts are shared turn by turn so both get an equal chance. Each performance gets a different introduction line, so a long list does not repeat the same sentence.

Read the script aloud at least twice the day before. Write names and titles (such as “District Magistrate”) exactly as they should be said — a wrong name on stage is what people notice most.

Anchoring tips

  • Hold the mic about a hand’s width away and speak slowly and clearly.
  • Pause for applause after each item before the next announcement.
  • Seat the next performers near the stage in advance so there is no dead time.
  • Make no announcement during the national anthem; ask everyone to stand before it starts.
  • Print the script in large type and number the pages.

Frequently asked questions

How do I start the anchoring?

Address the chief guest, principal, teachers, parents and students, welcome them, then say in a line or two why the day matters.

What is the order of a 26 January programme?

Welcome → flag hoisting and anthem → lamp lighting → welcome address → cultural programme → chief guest’s address → prizes → vote of thanks and Jai Hind.

What if there are two anchors?

Enter the second anchor’s name — the parts are shared between both names automatically.

Can I change the script?

Yes — copy it and edit the words; every line you write in the programme list becomes one announcement.
