🚗 Which district is MH-33?

MH-33 = Gadchiroli RTO, Maharashtra

RTO officeGadchiroli
AreaEntire Gadchiroli District
StateMaharashtra (MH)

How to read a number plate

  • First 2 letters — the state (e.g. MH)
  • Next 2 digits — the RTO code (e.g. 33)
  • Then 1–2 letters — the series (e.g. AB)
  • Last 4 digits — the vehicle number (0001–9999)
  • BH series (e.g. 22 BH 1234 AA) belongs to no single state — for people whose jobs move them between states

Basic details of any vehicle (except the owner’s name) can be checked under "Know Your Vehicle Details" on parivahan.gov.in.
